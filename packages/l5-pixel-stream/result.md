### Задание
Исследовать разные реализации прохода (по колонкам/по строкам) пикселей в изображении

Для исследования были применены четыре реализации:
- Плоский массив с числами
- Массив массивов пикселей в виде RGBA[]
- Массив объектов { r, g, b, a }
- Типизированный массив Uint8ClampedArray

### Выводы прохода без мутаций

- Самым эффективным оказался массив с массивами пикселей. Скорее всего из-за того что не происходит лишний аллокаций в памяти, т.к. у нас уже возвращается готовый массив значений.
- Неплохо показал себя в обходе по строкам массив объектов
- А вот плоские массив чисел и типизированный массив показали наихудший результат (примерно одинаковый), видимо из-за дополнительных аллокаций памяти и необходимости считать смещение байтов на лету.

### Выводы по проходу с мутациями
На небольших размерах изображений лидером остаётся массив массивов, но вот уже на изображениях большого размера уже видна стоимость создания новых объектов-пикселей,
в то время как перезаписывание значений в плоских массивах стоит намного дешевле. И во всех случаях проход по строкам обычно быстрее, особенно это заметно на больших размерах изображений.
